# ⚡ THE GLITCH LAB

> Reality is optional. Welcome to the unknown. ◈

**The Glitch Lab** is a futuristic, cyberpunk-inspired website built using HTML and CSS. It features glitch effects, neon colors, animated text, and a system diagnostics dashboard designed to look like a mysterious digital control room.

## ✨ Features

* ⚡ **Glitch Typography:** Animated text effects using CSS.
* 🟣 **Neon Aesthetics:** Futuristic purple, green, and black color palette.
* 🪟 **Glass-Inspired UI:** Dark cards with glowing borders and hover effects.
* 📊 **System Dashboard:** Visual indicators for system power, dimensional stability, and unknown entities.
* 💻 **Terminal Interface:** A fictional system log with a blinking cursor effect.
* 🖱️ **Interactive Button:** A button that displays a JavaScript alert.
* 📱 **Responsive Design:** Layout adapts to different screen sizes.
* ♿ **Reduced Motion Support:** Respects users who prefer reduced animation.

## 🛠️ Tech Stack

| Technology   | Purpose                                     |
| ------------ | ------------------------------------------- |
| HTML5        | Website structure                           |
| CSS3         | Styling, animations, and responsive layouts |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Navigate to the project directory

```bash
cd glitch-lab
```

### 3. Run the website

Open `index.html` in your preferred web browser.

**No installation or build tools required!**
